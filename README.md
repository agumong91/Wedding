# 모바일 청첩장

11월 겨울 테마 · 눈 내리는 연출 · 유튜브 영상 섹션 포함

## 파일 구조

```
wedding/
├── index.html      ← 기본 뼈대 (수정할 일 거의 없음)
├── config.js       ← 신랑·신부·예식·계좌·영상 정보를 여기서 수정
├── script.js       ← 동작 로직 (수정 불필요)
├── styles.css      ← 디자인/색상 (원하면 색만 조정)
└── images/
    ├── hero/       ← 1.jpg (메인 사진, 필수)
    ├── story/      ← 1.jpg, 2.jpg ... (스토리 사진)
    ├── gallery/    ← 1.jpg, 2.jpg ... (갤러리 사진)
    ├── location/   ← 1.jpg (약도 이미지)
    └── og/         ← 1.jpg (카톡 공유 썸네일)
```

## 수정 방법

- **정보 변경**: `config.js` 파일만 열어 이름·날짜·장소·계좌·유튜브 링크를 바꾸면 됩니다.
- **사진 추가**: 각 `images` 하위 폴더에 `1.jpg`, `2.jpg` … 순번으로 넣으면 자동으로 표시됩니다. (jpg/jpeg/png 지원)
- **눈 조절**: `config.js`의 `snow.density` 숫자를 바꾸면 눈송이 개수가 조절됩니다.
- **영상 숨기기**: `config.js`의 `video.youtube` 값을 `""`로 두면 영상 섹션이 사라집니다.

## 로컬에서 미리보기

이미지 자동 감지 때문에 파일을 더블클릭해서 여는 것보다 간단한 로컬 서버로 여는 것을 권장합니다.

```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```
